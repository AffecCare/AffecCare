# 💎 AffecCare ML 引擎：鉅細靡遺技術白皮書

> **文件版本**: v1.2 (Production Deep-Dive)
> **核心架構**: XGBoost + Scikit-Learn Pipeline + Custom Thresholding
> **目標**: 極大化員工離職預警的商業價值

---

## 🏗️ 第一層：數據資產 (The Data Foundation)

### 📊 `data/hr_data.csv` 數據多維解析
這不只是一個試算表，它是**員工行為的數字鏡像**。

- **特徵工程細節 (Feature Engineering)**:
    - **薪酬維度**: `Compa-Ratio` (員工薪資與市場中位數比) 是預測關鍵。數值低於 0.8 通常與高度離職風險正相關。
    - **心理維度**: `Engagement Score` 來自定期的員工滿意度調查，作為非結構化情緒的結構化指標。
    - **穩定度維度**: `Tenure` (年資) 捕捉了職涯瓶頸期（如入職第 2-3 年的震盪期）。
- **雜訊過濾策略 (Target Filtering)**:
    - **排除 Target=1 (非自願離職)**: 被公司資遣的員工特徵與「主動想走」的員工完全不同。將其移除是為了防止模型產生「認知混淆」，確保預測的是**員工的主觀意圖**。
- **資料型別優化**: 
    - 使用 `np.float32` 進行計算，在不損失精度的前提下，提升了 XGBoost 在大數據量下的記憶體吞吐效率。

## 🧠 第二層：模型中樞 (The Intelligence Core)

### 🔮 `models/voluntary_risk.pkl` 技術規格
這是一個封裝了「經驗」與「判斷規則」的物件。

- **集成學習架構 (Ensemble Method)**:
    - 內含 100 棵決策樹。每棵樹都在修正前一棵樹的錯誤（Residual Mapping），最終形成一個強大的預測森林。
- **Pipeline 自動化容器**:
    - **預處理封裝**: 內嵌了 `SimpleImputer(strategy='median')`。這意味著即使未來資料缺漏（例如某員工沒填問卷），模型也會自動用中位數填補，不會噴錯。
    - **原生成長權重**: 設置了 `scale_pos_weight: 3.0`。
        > **創辦人筆記**: 這是我們解決「離職者是少數」問題的神奇配方。它告訴 AI：抓到一個想走的人，比抓到三個想留的人更重要。

## 📝 第三層：實驗日誌與診斷 (Audit & Diagnostics)

### 📜 `models/tuning_report.json` 暴力破解報告
這份 JSON 是科學決策的鐵證，證明我們沒有「通靈」。

- **81 組參數交叉驗證**:
    - 我們在 `learning_rate` (步長)、`max_depth` (樹深) 之間進行了網格搜索。
- **深度選擇決策 (Why Max_Depth = 3?)**:
    - 雖然 `depth=5` 在訓練集表現更好，但 `depth=3` 的**標準差 (Std Dev) 最低**。
    - **結論**: 淺層模型更穩定，能抵禦不同部門間的資料差異，降低過度擬合 (Overfitting) 風險。

### 📈 `plots/` 可視化分析
- **混淆矩陣 (Confusion Matrix)**: 
    - 將 Threshold 設為 0.3，我們成功將 **Recall 提升至 77%**。這是一項重大的商業決策轉移——從「追求準確度」轉向「追求捕獲率」。
- **PR 曲線 (Precision-Recall)**: 
    - 我們的曲線遠高於 0.3 的基準線，AP 值達 0.548。這證明即使在充滿干擾的 HR 資料中，AI 依然能精確鎖定訊號。

## ⚙️ 第四層：邏輯管線 (The MLOps Pipelines)

### 🛠️ `train.py` (自動化優化工廠)
- **職責**: 負責模型的「進化」。
- **特點**: 
    - 採用 **Stratified K-Fold (5摺)**。確保每一份測試資料中，離職者的比例都與原始資料一致，避免評估偏差。
    - 自動化存檔機制：每次訓練都會生成新的 PKL 與 JSON，實現模型版本控制。

### ⚖️ `evaluate.py` (嚴謹性裁決所)
- **職責**: 負責模型的「體檢」。
- **特點**:
    - **不參與訓練**: 它是獨立的。它讀取 PKL 成品，用它從未見過的資料進行模擬測試。
    - **商業邏輯映射**: 將機率值 (0~1) 映射到預警清單，是後端 API 調用的前導邏輯基礎。
